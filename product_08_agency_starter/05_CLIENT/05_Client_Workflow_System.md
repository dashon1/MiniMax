## MODULE 1 — NOTION CLIENT HUB

Create one database in Notion called "Clients." Every client gets one page.

### Client Page Template

Create these properties on every client page:

| Field | Type | What It Tracks |
|---|---|---|
| Name | Title | Client full name |
| Email | Email | Primary contact |
| Company | Text | Their company |
| Service | Select | What you're delivering |
| Stage | Select | Lead / Qualified / Proposal / Active / Done |
| Start Date | Date | When engagement starts |
| Price | Number | Total project/retainer value |
| Next Action | Text | What needs doing next |
| Next Action Date | Date | When to do it |
| Renewal Date | Date | When to check in for renewal |

### Client Page Sections (Add to each page)

```
## Project Overview
[Copy scope from proposal here]

## Key Dates
- Kickoff: [date]
- Delivery: [date]
- Review call: [date]

## Communication Log
[Use this section to log every interaction]

## Deliverables
- [ ] [Deliverable 1]
- [ ] [Deliverable 2]
- [ ] [Deliverable 3]

## Notes
[Anything important to remember about this client]
```

## MODULE 2 — INTAKE FORM (Automated)

Create a simple Typeform or Tally form for new inquiries:

**Questions to ask on the form:**
1. What's your name and company?
2. What's the biggest challenge you're trying to solve right now?
3. What's your timeline? (ASAP / 1 month / 3 months / Just exploring)
4. What's your budget range? ($297–$997 / $1K–$3K / $3K+ / Not sure yet)
5. How did you find me?

**Automation:** Form submission → Notion page created → Welcome email sent → Task created to follow up within 24 hours

Set this up in Zapier once. It runs forever.

## MODULE 3 — PROPOSAL SYSTEM

### Proposal Structure (Copy and paste into a Google Doc)

```
[YOUR SERVICE NAME]

[Client Name]
Prepared by: [Your Name]
Date: [Today's date]

━━━ EXECUTIVE SUMMARY ━━━
I help [type of client] who want [outcome]. We will [what you do], so that [the result they get].

━━━ SCOPE OF WORK ━━━
In this engagement, you will receive:
1. [Deliverable 1] — [description]
2. [Deliverable 2] — [description]
3. [Deliverable 3] — [description]

━━━ TIMELINE ━━━
We will begin on [start date] and deliver the completed work by [delivery date].

━━━ INVESTMENT ━━━
The investment for this engagement is [price], due [payment terms].

━━━ WHAT HAPPENS NEXT ━━━
Once you confirm, I will send over a contract and invoice. We'll schedule a kickoff call within 2 business days.

To confirm: Reply to this email or sign below.

[Your signature / Docusign link]
```

## MODULE 4 — CONTRACT TEMPLATE (Basic Service Agreement)

```
SERVICE AGREEMENT

This agreement is between [Your Name] ("Service Provider") and [Client Name] ("Client").

1. SCOPE OF WORK
[Description of deliverables and any limitations]

2. TIMELINE
[Start date] to [end date]. Deliverables due [date].

3. REVISIONS
[Number] rounds of revisions are included. Additional revisions are billed at [rate].

4. PAYMENT
[Price] due upon signing this agreement. [Payment terms].

5. COMMUNICATION
Service Provider will provide [weekly/bimonthly] status updates via email.

6. CONFIDENTIALITY
Both parties agree to keep client information confidential.

7. CANCELLATION
Either party may cancel with [X days] written notice. Client pays for work completed to date.

8. DELIVERY
Work is considered delivered when sent via email or shared via cloud link.

[Your Name]        [Client Name]
Date:               Date:
```

## MODULE 5 — COMMUNICATION TEMPLATES

### Pricing Email (Sent with Proposal)

```
Subject: [Your Service] — proposal for [Company]

Hi [Name],

Following our conversation, I've put together a proposal for [service description]. You can view it here: [link to proposal document].

Investment: [price]
Timeline: [timeframe]

The proposal includes the full scope, timeline, and what happens next. If you have any questions, I'm happy to walk through it with you.

[Your Name]
```

### Scheduling Confirmation (After They Sign)

```
Subject: Confirmed — [Service] kickoff

Hi [Name],

You're all set. Our kickoff call is scheduled for [date/time]. You'll receive a calendar invite shortly.

Before the call, I'll send a quick briefing on what to expect.

Looking forward to it.

[Your Name]
```

### Weekly Check-In (During Active Project)

```
Subject: Week [X] update — [Project Name]

Hi [Name],

Quick update: We're at [milestone status]. Here's what's done, what's in progress, and what's coming up.

[3-4 bullet points]

Anything you need from me? Just reply.

[Your Name]
```

### Project Complete (Final Delivery)

```
Subject: Complete — [Project Name]

Hi [Name],

Delivered as promised. [Link to deliverables].

If everything looks good, I'll close the project and send over a final summary.

[Your Name]
```
