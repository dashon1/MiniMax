## ⚠️ IMPORTANT: COPPA Compliance
This channel targets kids under 13. You MUST:
- Set each video as "Made for Kids" in YouTube Studio → Edit Video → Audience
- Do NOT collect personal data from viewers
- The SEO file has a reminder and the description is COPPA-friendly

Failure to comply can result in fines. The SEO package guides you through this.
