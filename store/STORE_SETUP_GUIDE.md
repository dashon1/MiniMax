## 3. SETTING UP ON GUMROAD

**URL:** gumroad.com → Sign up → Add payout method

### For Each Product, Follow These Exact Steps:

**Step 1:** Dashboard → "New Product" → "Digital product"

**Step 2: Name (Product Title)**
Paste the Product Title from the corresponding listing file.

**Step 3: Summary**
Paste the Short Description (2-3 lines) from the listing file.
This shows in marketplace browse — make it count.

**Step 4: Description (Full Sales Page)**
Paste the FULL PRODUCT DESCRIPTION from the listing file.
Gumroad renders markdown — headers and bullet points display correctly.

**Step 5: Price**
Enter your chosen price. Keep "pay what you want" OFF for perceived value.

**Step 6: Cover Image**
Upload the thumbnail JPG for that product:
- Kit 1: 01_NaturalHealing_Thumbnail.jpg
- Kit 2: 02_RicherByDesign_Thumbnail.jpg
- Kit 3: 03_Aria_Thumbnail.jpg
- Kit 4: 04_Dashon_Thumbnail.jpg
- Mega Bundle: Use Kit 4 thumbnail or create a composite

**Step 7: Content / Upload File**
Upload the corresponding ZIP file.

**Step 8: Tags**
Add tags from the "Gumroad Tags" list in each listing file (max 10 tags).

**Step 9: Publish**
Click Publish. Copy your product URL for marketing.

**Repeat for all 5 products.**

### Gumroad Bundle Cross-Sell Setup
Gumroad lacks a native bundle tool. Workaround:
1. Create the Mega Bundle as its own separate product
2. On each individual kit page, add at the bottom of the description:
   > "Want all 4 kits? Get the [Mega Bundle](YOUR_URL) and save $51."

### Gumroad Discount Codes
Dashboard → Product → "Discount codes" tab → "Add discount"
- Code: LAUNCH27 (for launch pricing)
- Type: Fixed amount ($10 off) or percentage
- Set expiry date for urgency

### Gumroad Affiliate Setup
Dashboard → Settings → Affiliates → Enable
Default commission: 10% (increase to 20-30% to attract active promoters)

## 4. SETTING UP ON PAYHIP

**URL:** payhip.com → Sign Up → Connect Stripe or PayPal

### For Each Product:

**Step 1:** Dashboard → "Add Product" → "Digital Download"

**Step 2: Product Name**
Paste the Product Title from the listing file.

**Step 3: Description**
Paste the FULL PRODUCT DESCRIPTION from the listing file.
Use Payhip's rich text editor to add headers and bold text.

**Step 4: Price**
Enter your price. Leave "Pay what you want" unchecked.

**Step 5: Product Image**
Upload the corresponding thumbnail JPG. Minimum 1280×720px recommended.

**Step 6: Upload File**
Click "Upload File" → Upload the corresponding ZIP file.

**Step 7: Tags**
Enter tags from the "Payhip Tags" list in each listing file.

**Step 8: Category**
Select "Templates & Tools" or "Education"

**Step 9: Settings**
- Visibility: Public
- Allow reviews: YES (critical for social proof)
- Download limit: Unlimited

**Step 10: Save & Publish**

**Repeat for all 5 products.**

### Payhip Bundle Cross-Sell / Upsell

Payhip has a built-in upsell feature:

1. On each individual kit product page → Settings → "Upsell"
2. Select the Mega Bundle product as the upsell
3. Set upsell price: $97 (or discounted $77 for upsell buyers)
4. Write upsell copy:
   > "You bought 1 kit — want all 4? Get the Mega Bundle (4 scripts, 4 SEO packages, 4 thumbnails, 8 clips) for just $97. That's $51 off vs. buying separately."

This single upsell can add 20-40% to your average order value.

### Payhip Discount Codes

Dashboard → Marketing → Discount Codes → Create Discount Code

For bundle launch discount:
- Code: MEGABUNDLE or SAVE51
- Discount: $51 off fixed OR 35% off
- Apply to: Mega Bundle product only
- Uses: 50 (creates scarcity) or Unlimited
- Expiry: 7 days from launch date

For individual kit launch:
- Code: LAUNCH27
- Discount: $10 off (brings $37 → $27)
- Apply to: All individual kit products
- Expiry: 48-72 hours from launch

## 6. PLATFORM COMPARISON

| Feature | Gumroad | Payhip |
|---------|---------|--------|
| Transaction fee (free plan) | 10% | 5% |
| Transaction fee (paid plan) | 0% ($10/mo) | 0% ($29/mo) |
| Marketplace discovery | Strong | Good |
| Native upsell/bundle tool | No (manual) | YES |
| Discount codes | Yes | Yes |
| Affiliate program | Yes (10% default) | Yes |
| Email list capture | Yes | Yes |

**Recommendation:** List on BOTH. They're free to start, attract different buyers, and both send organic traffic your way. Start with Gumroad for marketplace discovery; add Payhip for its superior upsell system.
