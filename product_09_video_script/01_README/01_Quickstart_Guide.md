## The 3-Second Hook (The Most Important Part)

The first 3 seconds decide whether someone watches or scrolls away. Every script in this kit starts with one of these:

| Hook Type | Example |
|---|---|
| Question hook | "Did you know 90% of people do this wrong?" |
| Statement hook | "Most people's first mistake is..." |
| Number hook | "Three things you must know before..." |
| Contrast hook | "Everyone talks about X. Nobody talks about Y." |
| Scene hook | "I just got back from a meeting where..." |

**Rule:** Write the hook first. Everything else is built to support it.
