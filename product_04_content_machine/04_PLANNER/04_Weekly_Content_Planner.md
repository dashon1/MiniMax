## BONUS: QUICK CONTENT AUDIT CHECKLIST

Run this before your next batch session to know what's working.

**Before each batch session, ask:**
- Did my top hooks from last week share a common pattern? → Note it
- Did a specific format outperform the others? → Do more of it
- Did any post get saves? (High intent — people want to come back) → Repurpose angle
- Did any post get shares? (Resonance — people want others to see) → Double down on topic
- Did any post get no engagement at all? → Try a different angle
