# Mastering OpenClaw | A Guide to Installing OpenClaw Skills and Practical Applications

If the combination of OpenClaw and large models gives us an intelligent AI assistant, then Skills are its \*\*“hands.”\*\* Skills can further expand the capabilities of our already deployed OpenClaw.
> \*\*Note:\*\* If you haven’t deployed your own OpenClaw yet, I strongly recommend starting from the [Tencent Cloud OpenClaw](https://www.tencentcloud.com/act/pro/intl-openclaw) to get an OpenClaw instance up and running first, then return to this tutorial to explore more possibilities.
## Experience the Default Integrated Skills
To allow everyone to quickly experience the capabilities of \*\*OpenClaw + Skills\*\*, we have integrated a browser operation plugin, `agent-browser v0.2.0`, into the latest version of the OpenClaw application template.
`agent-browser` is a browser tool that supports AI Agents. AI Agents can browse pages, click, enter text, and take page snapshots using structured commands.
The demonstration here is based on \*\*Telegram Bot\*\*. If you want to integrate your OpenClaw with Telegram Bot, you can refer to the [Telegram Bot integration guide](https://www.tencentcloud.com/techpedia/139185) for more information.
> \*\*⚠️ Note:\*\* After multiple tests, we found that when using the default integrated Skills to complete a task for the first time, OpenClaw may not yet be aware of the existence of the default integrated Skills. Therefore, before starting, you can first let it see what Skills are available, and then execute the specific task.

```
Use your browser to visit Baidu and see what content is displayed on the page.
```

Having browser control capabilities, OpenClaw naturally possesses the ability to search for information. Here, we’ll try having it search for today’s trending news. You can directly copy either of the following prompts:

```
Search for today’s 5 trending news items using your browser.
```

```
Please help me find today's top 5 trending news stories using your browser.
```

## How do I install new Skills?
### Install directly via OpenClaw chat
You can also install the Skills you want to use directly through a chat with OpenClaw. Of course, the Skill still needs to be listed in `Clawhub/Skills`. Here, we’ll use \*\*Telegram Bot\*\* and \*\*McDonald’s Assistant (`/mcd`)\*\* as examples.
First, you need to ensure you can currently chat with OpenClaw normally. Then refer to the instruction below to tell OpenClaw which Skill you want to install:
```
Please install a skill for me using Clawhub; its name is mcd.
```
If all goes well, the installation will be successful immediately.
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1\*fQF0ZxCvzJCeBxeUS-9FTQ.png)
> \*\*⚠️ Note:\*\* If you select a Skill marked as \*\*high-risk\*\* on Clawhub, OpenClaw will alert you and ask for a second confirmation regarding installation. At that point, you need to decide whether to proceed.
>
> Our recommendation is simple: if you are \*\*100% familiar\*\* with the Skill you are installing, then you can proceed; otherwise, install it with caution.
Of course, you can also verify the successful installation by having OpenClaw check the usage instructions for the Skill:
```
Please check its usage instructions for me.
```
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1\*cBbrh53KTDlm8K9u9muL0w.png)
The installation has now been successfully completed.
## Uninstalling Skills
If you have installed Skills that you no longer use, you can follow the instructions in this section to remove them.
Similar to installing Skills via OpenClaw dialog, deletion can also be handled by OpenClaw.
First, let’s have OpenClaw check the currently installed Skills:
```
Check which skills you have currently installed.
```
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1\*rxfp94Qihz3a8qNlSoJWNA.png)
Next, find the Skill you want to delete, such as `mail` here:
```
Please help me delete the "mail" skill.
```
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1\*vbUvsIfqcZ-UvKFn3BmZ6w.png)
If all goes well, the deletion should complete successfully. Of course, due to differences in models or the characteristics of a specific OpenClaw setup, it may warn you to delete with caution; if that happens, simply continue the dialog and follow its guidance.

If you want to continue extending your bot with Telegram-related capabilities, the [Telegram Bot integration guide](https://www.tencentcloud.com/techpedia/139185) is also worth keeping nearby.
