What is Agent Browser?
----------------------

Agent Browser is an OpenClaw skill. A fast Rust-based headless browser automation CLI with Node.js fallback that enables AI agents to navigate, click, type, and snapshot pages via structured commands. It belongs to the [Productivity](/skills/category/productivity.html) collection. For background, see [MCP Server - Puppeteer (Browser Control)](/wiki/integrations/mcp-server-puppeteer.html) in our wiki.

Agent Browser是一款基于Rust的无头浏览器自动化命令行工具，支持Node.js，赋能AI智能体通过结构化指令实现网页导航、点击、输入及截图等操作。

Agent Browser has 58.6K+ downloads. One of the most used OpenClaw skills. 304 stars from users. 668 active installs.

How to Install Agent Browser
----------------------------

Installing Agent Browser in OpenClaw takes just one command. Make sure you have OpenClaw set up and running before proceeding.

1
### Install the Skill

Run the following command in your terminal to add Agent Browser to your OpenClaw instance:

```
openclaw skill install agent-browser
```


2
### Verify Installation

Confirm the skill is properly installed and ready to use:

```
openclaw skill list
```


3
### Start Using

The skill is now available in your OpenClaw conversations. Simply describe what you want to accomplish, and OpenClaw will automatically invoke Agent Browser when relevant.
